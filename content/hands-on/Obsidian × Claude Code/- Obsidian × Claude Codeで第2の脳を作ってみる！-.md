## ブームのきっかけ

今回の Obsidian × Claude Code（LLM）のブームは、
先日 [[OpenAI 共同創設者 Andrej Karpathy 氏が Anthropic に参画|こちら]] でも取り上げた、AIを熟知している Andrej Karpathy さんの下記ツイートから始まったらしいです。

[Andrej Karpathy氏のポスト (@karpathy)](https://x.com/karpathy/status/2039805659525644595?s=20)

![[Pasted image 20260521010550.png|500]]

ざっくり内容としては

> [!note] ツイートの要旨
> LLMに個人用Wiki（Markdown形式の知識ベース）を作らせて運用するワークフローの紹介で、
> 人間は元データを集めるだけで、要約・記事化・リンク付け・整合性チェック・質問への回答まで
> 全部LLMにやらせ、Obsidianで眺める。Wikiが育つほどLLMの回答精度も上がっていく
> ——という「知識管理をLLMに任せる」やり方を提案させる。

…ということのよう（詳細は元のポスト参照）。

## 「ふむふむ、なるほどねぇ～。ようわからん！」

とりあえず、*"第2の脳"* っていうのは、どうやら人それぞれが興味・関心を持っている内容の元データを集めて、Obsidianに集約させておいて、それを Claude Code しかり LLM にやらせると、**自分専用のWikiができていく**ということなのか？

ということは、Obsidianに自身の知識や興味のある情報を収集しておけば、あとはAIがwikiとしてまとめてくれるってこと、、、これが上手くハマったら、ようやく情報整理おじさんの呪いからも解放されるかもしれない！！

…まぁでも、元データを集めるところが大変そうだな。

なんて右に左に揺られながらも、とりあえず実際にやってみようということで、
以下のような感じで進めていこうかなと思います。

1. Obsidian のインストール
2. Obsidian の同期設定
3. 知識の構築をするためのフォルダ整理
4. Claude Skills の準備
5. 元データの収集と wiki の作成
6. しばらく運用してみて

もし、既に活用している人がいたら**使用感を是非教えて欲しいです！**
